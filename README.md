**Description :**  
Ce projet est un petit jeu web développé pour apprendre et maîtriser les bases de JavaScript. Le concept est simple : l'utilisateur doit réécrire correctement les mots affichés à l'écran pour gagner des points.

**Fonctionnalités :**
* Affichage dynamique de mots.
* Système de score en temps réel (Bonne réponse = 1 point).
